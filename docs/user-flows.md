### OAuth Flow

```
┌─────────────────────────────────────────────────────────────┐
│                 LOGIN/SIGNUP PAGE                            │
│                                                              │
│  [Google]  [Microsoft]                                      │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│              OAUTH PROVIDER PAGE                             │
│          (Google/Microsoft login screen)                    │
│                                                              │
│  User authenticates with provider                           │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│                  CALLBACK PAGE                              │
│              (/auth/callback)                                │
│                                                              │
│  - Exchange code for session                                │
│  - Create/update user profile                              │
│  - Redirect to dashboard or onboarding                     │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│           ONBOARDING (new users) or DASHBOARD (existing)    │
└─────────────────────────────────────────────────────────────┘
```
